Evidence language

Słowa też są częścią systemu kontroli ryzyka

W publicznej kronice jedno słowo może zawyżyć stan projektu bardziej niż błąd w kodzie. Dlatego D-LOGIC przypisuje konkretny zakres takim określeniom jak „zbudowałem”, „przetestowałem” czy „odkryłem”.

SformułowanieWarunek użycia
ZBUDOWAŁEMKod lub artefakt istnieje i można wskazać jego wersję. Nie oznacza to, że działa w runtime albo posiada edge.
WDROŻYŁEMKomponent działa w jawnie nazwanym środowisku: read-only, shadow, demo albo live.
TESTUJĘHipoteza albo komponent ma określony protokół, status i warunki zakończenia.
ODRZUCIŁEMSpełniono wcześniej ustalone kryterium falsyfikacji albo zamknięcia kierunku.
PODEJRZEWAMTo hipoteza lub inference. Nie jest przedstawiana jako wynik.
ODKRYŁEMWynik przeszedł właściwą walidację, kontrolę liczby prób i posiada jawne ograniczenia.
SYSTEM ZARABIANiedozwolone bez pełnej, aktualnej i audytowalnej historii live po kosztach.

Etykiety prawdy

  • CURRENT FACT - potwierdzone przez aktualny runtime, audyt, test, hash albo artefakt.
  • HISTORICAL FACT - potwierdzone przez datowany dokument lub kod z danej epoki.
  • SOURCE-ERA CLAIM - dawne twierdzenie projektu, niepotwierdzone jako stan aktualny.
  • INFERENCE - logiczny wniosek wymagający ostrożności.
  • AMBITION - cel projektowy, nie wynik.
  • UNKNOWN - brak wystarczających danych.
  • SUPERSEDED - element zastąpiony późniejszym rozwiązaniem.
  • REJECTED - hipoteza albo komponent odrzucone dowodami lub decyzją architektoniczną.

Zakazane skróty

  • architektura -> alpha,
  • zielony test suite -> działający runtime,
  • kompilacja -> prawidłowe dane,
  • backtest -> OOS,
  • OOS -> forward,
  • forward -> execution readiness,
  • ruch rynku -> codzienna okazja netto.

Najbardziej profesjonalne twierdzenie nie jest największym twierdzeniem, jakie da się obronić retorycznie. Jest najmniejszym twierdzeniem, które dokładnie odpowiada dostępnemu dowodowi.

Ochrona własności intelektualnej

Transparentność dotyczy standardu dowodowego i statusu projektu. Nie oznacza publikowania prywatnych danych, kodu produkcyjnego, pełnych wzorów, konfiguracji, feature sets, parametrów, progów, danych rachunku ani kompletnej logiki wykonawczej.
